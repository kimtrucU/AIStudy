# AI Study Mentor (AI Study)

AI Study Mentor is a native Android app that helps students understand homework. A learner asks a question by typing or with a photo, receives a step-by-step explanation generated by the Google Gemini API at their chosen level, and can review past questions, practise with quizzes and follow their progress.

## 3. Configuration (API key)

The Gemini API key is **never stored in the repository**.

1. Use the Gemini API key provided by the lecturer for this unit. Do not share it, commit it or paste it into chat; billing for the key is managed by the lecturer.
2. Open `local.properties` in the project root (create it if missing) and add one line:

   ```properties
   GEMINI_API_KEY=your_key_here
   ```

   No spaces and no quotation marks.
3. In Android Studio choose **File → Sync Project with Gradle Files**.

The build reads this value into `BuildConfig.GEMINI_API_KEY`. If it is missing, the app shows *"Gemini API key is not configured in BuildConfig."* and does not send the question.

Security notes:
- `local.properties` is listed in `.gitignore`; check that it never appears in a commit.
- The key is compiled into the APK of this version. Do **not** share APK files or the `build/` folders, and do not put the key in screenshots, reports or chat messages.

## 4. Build and run

**Android Studio**
1. *File → Open* and select the project folder.
2. Wait for Gradle sync to finish.
3. Select the `app` run configuration and a device or emulator (Android 13+).
4. Press **Run ▶**.

**Troubleshooting**
- *"Device is offline"* in Android Studio: unplug and reconnect the USB cable, accept the *Allow USB debugging* prompt on the phone (revoke USB debugging authorisations in Developer options first if it does not appear), or run `adb kill-server` then `adb start-server`.
- *"Gemini API key is not configured in BuildConfig"*: the key line in `local.properties` is missing or the file was not saved; save it, sync Gradle and run again.
- Logcat `GeminiClient` shows *HTTP 402 RESOURCE_EXHAUSTED*: the key has no prepaid credit left. Ask the lecturer to add credit or issue a new key; the app will show built-in example answers until then.

**Command line** (Windows: `gradlew.bat`)
```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## 5. User guide

1. **Sign up / Sign in** – create an account with e-mail and password (stored only on the device).
2. **Onboarding** – choose your level (junior, high school, university), subjects and explanation style (short, step-by-step, detailed).
3. **Home** – daily goal and XP, AI Chat shortcut, Quick Scan, Flashcards, weekly Study Plan and questions per subject.
4. **Ask** – type a question, use a shortcut (Summarize text, Explain a concept, Solve an equation) or attach a photo with **Camera** / **Gallery**, then tap Send.
5. **Answer** – numbered steps, final answer, subject and difficulty; open *Study Extras & Quiz* for a simpler or alternative explanation, key concepts and common mistakes.
6. **History** – all your questions, newest first, with search, subject filters and stars.
7. **Progress** – XP and level, day streak, number of questions, quiz accuracy, review time and per-subject breakdown.
8. **Quiz** – available for a subject after at least two questions in that subject.
9. **Notifications** – a daily learning reminder (allow notifications when asked).

## 6. Architecture note

```
UI (Activities + Fragments, XML layouts)
  ├─ auth        LoginActivity, RegisterActivity, PasswordHasher
  ├─ onboarding  OnboardingActivity
  ├─ home        HomeFragment
  ├─ ask         AskFragment, AskChatAdapter, GeminiClient  ──► Google Gemini API (HTTPS)
  ├─ answer      AnswerActivity
  ├─ history     HistoryFragment, HistoryAdapter
  ├─ progress    ProgressFragment
  ├─ quiz        QuizActivity
  ├─ xp          XpRules, UnlockCatalog, FriendSeeder
  ├─ notify      DailyLearningWorker, NotificationScheduler, NotificationHelper (WorkManager)
  └─ view        CustomBottomNavView
Data: Room database (AppDatabase) – User, Profile, QuestionAnswer, QuizItem, QuizSession, Friend
```

- All data is stored locally on the device; there is no cloud back end in this version.
- `GeminiClient` sends the question (and optional image as base64) with the learner's level and style, and parses a JSON answer (subject, difficulty, steps, final answer).

## 8. Testing

**Unit tests**
```bash
./gradlew test
```
or right-click `app/src/test` → *Run 'Tests in app'*. Tests cover password hashing (`PasswordHasher`), XP rules (`XpRules`) and unlock rules (`UnlockCatalog`).

**Manual test checklist** (record date, device, actual result and Pass/Fail):
1. Register, sign out and sign in again; wrong password is rejected.
2. Ask a typed question → structured answer appears and is saved in History.
3. Ask with a photo (Camera/Gallery) → answer refers to the exercise.
4. Logcat, tag `GeminiClient` → `response httpCode=200`, no "built-in study tutor fallback".
5. Close and reopen the app → History still lists the questions.
6. Ask two questions in one subject → Quiz becomes available; finish it → Progress shows quiz accuracy.
7. Airplane mode → History opens; sending a question should show an error (current version: shows a built-in example answer instead).

## 9. Known limitations

- Data is stored only on the device (no sync or restore on another phone).
- No guardian-consent step for learners under 16.
- No daily request limit or usage logging for the AI service.
- Leaderboard friends are demonstration data.
- If every Gemini request fails (for example HTTP 402 when the key has no credit, or no network), built-in example answers are shown and saved without a warning.
- Home shows placeholder figures (85 % daily goal, study plan bars) and can stay blank right after sign-in until another tab is opened.
- Requires Android 13 or later.
